## 📌 核心研究方法论 (Five-Dimensional Methodology)

每一份研报均严格经由五维穿透流水线独立审计：

1. **维度 1【赛道方向与叙事流行线】**：是否踩在当前核心主流资金流行线上（如 DEX、编程 Hook、隐私、AI/AI Agent、RWA、封矿封盘币、高技术明文协议等）；
2. **维度 2【开发者 / 团队底细深扒】**：核心操盘团队牛不牛逼？以前做过什么成功破圈项目？是技术极客还是无战绩草台班子；
3. **维度 3【真实社交热度】**：社区与 Twitter/X 声量是真实极客大 V 自发研讨，还是水军脚本刷量自嗨；
4. **维度 4【业务深度真实评估 (防割验真)】**：到底是真有底层技术能解决实际行业痛点，还是纯粹跟风概念、发币割一波就跑的空气项目；
5. **维度 5【发币情况与实盘落地 (二浪研判)】**：
   - **未发币**：短期能否公平、低成本获取筹码？
   - **已发币**：二级盘面是在蓄力还是一波流走成了“圣诞树”阴跌？结合前四项综合研判**是否存在第二浪（二浪爆发）的机会**！

详细方法论拆解见：[📘 五维方法论详述 (Methodology)](./methodology/five_dimensions.md)
