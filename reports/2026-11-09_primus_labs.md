#### 4. 大白话三步业务流与产品真容
1. **本地建立加密见证会话**：用户在浏览器安装 Primus Extension 插件并登录目标网站（如 X、GitHub、Polymarket），插件在本地通过 MPC-TLS 或 Proxy-TLS 模式与远端服务器通信，见证节点（Attestor）仅验证 TLS 握手与响应包签名真伪，无法窥探用户明文密码与完整隐私。
2. **零知识证明生成（ZK Proof）**：客户端针对特定条件（例如“我的 GitHub 提交次数大于 X”或“我在 Hyperliquid 有真实交易记录”）在本地生成轻量化零知识证明。
3. **链上结算与积分确权**：用户调用 EVM 钱包在 Base 链上发起确认交易，支付微量网络验证费（约 0.000035 Base ETH + 基础 Gas），智能合约校验签名通过后将验证状态写入链上，并向用户账户发放对应任务的 XP 积分。
