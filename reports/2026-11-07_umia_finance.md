#### 4. 大白话三步业务流与产品真容
1. **第一步：zkTLS 隐私验资与白名单准入（防女巫阶段）**
   用户安装 Umia Chrome 浏览器扩展插件（底层调用 Reclaim Protocol 的 zkTLS 技术），在本地浏览器内验证自己的链下贡献凭证（例如在 GitHub 上的有效 PR 合并记录），生成零知识证明提交上链，无需暴露个人身份信息即可获得专属优先竞标资格。
2. **第二步：定制化连续清算拍卖（CCA 价格发现阶段）**
   进入公开拍卖窗口后，代币按区块匀速释放。参与者输入「总预算金额」与「最高可接受单价（Max Price）」。订单在剩余所有区块内持续有效，系统在每个区块优先撮合出价上限最高的买单，同一区块内成交者支付完全相同的清算价格；若触及价格硬顶（如 $SLOP 的 0.02196 USD），系统按比例缩减配额并将未消耗的预算自动原路退还。
3. **第三步：非托管国库拨款与 Futarchy 决策市场（投后治国阶段）**
   拍卖结束瞬间，20% 资金自动配对代币注入 DEX 形成协议自有流动性（POL），其余资金锁入非托管链上国库。日常研发按月定量自动释放；若团队申请额外预算或重大战略变更，系统自动开启「通过（Pass）」与「否决（Fail）」两个条件代币交易市场，完全由真金白银的交易价格高低决定提案是否由合约自动执行。
